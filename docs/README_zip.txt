doom-meego v1.1
===============

RU: Распакуйте в корень SD-карты: AppUpgrade, .lge.upgrade.xml, README.txt, папка WAD\.
Положите freedoom1.wad (или другой IWAD) в WAD\ или рядом с AppUpgrade.
Несколько WAD — меню выбора при запуске. Chex Quest (CHEX.WAD) поддерживается.
Кнопки — прямое чтение MICOM. При камере ЗХ / уходе в меню магнитолы кнопки отпускаются.

EN: Unpack into the SD card root: AppUpgrade, .lge.upgrade.xml, README.txt, WAD\ folder.
Put freedoom1.wad (or another IWAD) in WAD\ or next to AppUpgrade.
Several WADs → selection menu. Chex Quest (CHEX.WAD) is supported.
Keys via direct MICOM read. On rear camera / HU menu, keys are released.
